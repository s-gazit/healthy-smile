# חיוך בריא – מרפאת שיניים

אתר דף בית למרפאת השיניים "חיוך בריא". האתר בעברית, מימין לשמאל, ומותאם למחשב, לטאבלט ולטלפון.

## מבנה הקבצים

```
index.html            הדף הראשי (HTML + CSS בקובץ אחד)
assets/
  logo.svg / .jpg     הלוגו של המרפאה
  header-icon.svg/.jpg  האייקון בכותרת ובלשונית הדפדפן
  bot-avatar.svg/.jpg   תמונת הצ׳אטבוט
```

## צפייה מקומית

פותחים את `index.html` בדפדפן בלחיצה כפולה.

## פרסום ב-GitHub Pages

1. ב-GitHub נכנסים למאגר ← **Settings** ← **Pages**.
2. תחת **Source** בוחרים **Deploy from a branch**.
3. בוחרים את הענף `main` ואת התיקייה `/ (root)` ולוחצים **Save**.
4. אחרי כדקה האתר זמין בכתובת שמופיעה באותו עמוד.

## צ׳אטבוט

הצ׳אטבוט מופעל דרך [Chatling](https://chatling.ai). הגדרות הבוט (תשובות, עיצוב, תמונה) נערכות בחשבון Chatling ולא בקוד האתר.

## לפני עלייה לאוויר

הכתובת, מספר הטלפון ושעות הפתיחה ב-`index.html` הם נתוני דוגמה. יש להחליף אותם בפרטים האמיתיים של המרפאה.
